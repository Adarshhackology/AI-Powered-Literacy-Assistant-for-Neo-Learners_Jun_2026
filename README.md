# AI-Powered Literacy Assistant for Neo-Learners — Module 1

Beginner-friendly Module 1 project using only Python, SQLite, HTML, CSS and JavaScript.

## Run the project

1. Install Python 3 from [python.org](https://www.python.org/downloads/) if it is not already installed. During setup, select **Add Python to PATH**.
2. Open this folder in VS Code.
3. Open the terminal (**Terminal → New Terminal**).
4. Run: `python app.py`
5. Open `http://localhost:8000` in your browser.

No extra packages need to be installed. Python creates `literacy_assistant.db` automatically.

## Included Module 1 features

- Learner registration and login
- Learner profile: age, language, education level and proficiency
- SQLite tables for users, profiles, curriculum, lessons, results and responses
- Beginner, Intermediate and Advanced curriculum structure
- English, Tamil and Hindi learning content
- Reading, writing, comprehension and communication assessment
- Automatic score and proficiency calculation
